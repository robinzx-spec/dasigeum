## 공개 전 해결해야 하는 불일치

1. **출석 정책:** 요청 정책은 매일 5P, 월 최대 100P. 앱 `src/app/today.tsx`는 매일 5원에 한 달 모든 날 출석 시 말일 100원 보너스를 안내. 실제 claim_daily_attendance 서버 지급 구현은 저장소에서 확인되지 않음. 초안은 요청 정책으로 작성했으며, 앱 안내·서버 로직과 일치하기 전 공개 불가(U05).
2. **동의 증빙:** 이메일 약관/방침 체크는 가입 화면·컨트롤러에서 확인하지만 서버에 버전/시각 등 증빙 저장은 확인되지 않음. Kakao/Naver 신규 회원의 약관 고지·동의 경로를 별도 확인해야 함(U02).
3. **비밀번호 복구:** 현재 비활성화. 이메일 소유 확인 없이 즉시 가입하므로 오입력·계정 소유권·복구 안내와 고객지원 절차 필요(U04). 이메일만으로 본인확인 완료를 표현하지 않음.
4. **탈퇴/잔액:** 탈퇴는 요청 접수이며 즉시 자동 삭제가 아님. 진행 중 정산, 최소 출금액 미만 잔액, Auth/identity·Vault·스냅샷·로그·백업 삭제 및 법정 분리보존 실행 확인 필요(U09/U12/U18). 삭제 방지 장부 설계는 영구 개인정보 보유의 근거가 아님.
5. **출금:** 수동 송금의 실제 기한·수수료·계좌 검증·세무·오송금 절차 미확정(U10/U22). 코드의 paid 상태는 은행 실제 입금 성공을 독립 검증한 결과가 아님.
6. **개인정보 법적 역할:** 통신 구현만으로 Supabase/LinkPrice/은행의 제3자 제공·위탁·국외 이전 관계를 확정하지 않음. 계약·리전·재위탁·실제 전달자료 확인 필요(U23~U25).

- 두 HTML의 lang=ko/UTF-8/viewport, h1, 22개·12개 section, 중복 ID 및 목차 anchor, 상대 링크를 정적 검증.
